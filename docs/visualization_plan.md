# 可视化分析方案

> 阶段：2026-08-04 ~ 2026-08-09｜输入：data/processed/jobs_clean.csv（681 行 × 29 列）

> 产出：6 个分析 notebook、静态图表（PNG）、聚合数据表、README 分析章节素材

## 1. 分析目标

回答项目背景提出的四个问题：哪些城市需求最旺？不同经验/学历的薪资带宽？

企业最看重哪些技能？核心岗 vs 泛数据岗定价差异？

每个问题至少落到「一张图 + 一句数据结论」。

## 2. 全局数据口径规则（所有图表统一遵守）

| 规则 | 说明 |

|---|---|

| 薪资统计口径 | 一律使用中位数 + P25/P75 带宽，不使用均值（分布右偏） |

| 极值处理 | 「26-37万」记录（月薪中位 31.5 万）全局剔除并在脚注声明；有效薪资样本 n=675 |

| 实习岗 | is_intern=1（4 条）不进入薪资统计 |

| 样本声明 | 每张图标注 n=，文本类分析声明可用样本口径（描述 635 / 要求 531 / 福利 522） |

| 小样本桶 | n<15 的分组只展示、不下结论，图中标注 |

| 城市口径 | 城市分析剔除「未知/全国」（7 条） |

## 5. 图表规范

- matplotlib / seaborn 静态图优先（保证 GitHub 与 README 可见）；

  pyecharts 仅用于加分项交互图，同时导出静态截图

- 中文负号正常显示；统一 seaborn 主题与配色；dpi ≥ 150

- 每图：结论式标题 + n= 标注 + 口径脚注

-涉及口径选择的分析，先验证后出图

## 7. 验收标准

1. 6 个 notebook 可从顶到底无错运行，GitHub 预览输出可见

2. README 六个分析维度各至少 1 图 + 1 句结论

3. 每张图含 n= 与口径脚注；无仅基于均值的结论；无小样本桶硬结论

4. 聚合数据表提交 docs/aggregates/

## 8. 风险与备选

| 风险 | 备选 |

|---|---|

| pyecharts 地图渲染/截图失败 | 降级为城市条形图，不影响主线 |

| wordcloud / jieba 安装失败 | 跳过词云（技能分析不依赖 jieba） |

| 某分组样本过薄 | 合并分组或仅展示，不强行结论 |
